# Offer photos

Drop a photo here named after the offer and it appears automatically on the
homepage offers row, the offers page, and in the Offer structured data. Leave
one out and that offer falls back to its icon, so the site looks finished
either way.

| File | Offer |
|---|---|
| `free-brake-inspection.jpg` | Free Brake Inspection + $25 Off Brake Repairs |
| `free-check-engine-scan.jpg` | Free Check-Engine-Light Scan |
| `free-diagnostic-with-repair.jpg` | Diagnostic Fee Waived |
| `oil-change-99.jpg` | $99 Oil Change |

Landscape, at least 800px wide, roughly 4:3 or 16:9. They are displayed as a
wide crop, so keep the subject centred.

Real photos of the actual work beat stock. The same generic garage image on
all four reads as filler, which is worse than the icons.

Run `npm run offers:photos` to see which are still missing.
